About Stella James

A New York-based jewelry house

Each Love Letter is cut from a single, solid lab-grown diamond using a first-of-its-kind technique. This innovation optimizes the stone’s surface to create a seamless, custom shape set in 18k gold—maximizing brilliance, strength, and meaning.
